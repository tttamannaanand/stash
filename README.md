### How to read the licence column

| Badge | Means |
|---|---|
| 🟢 | Free for personal **and** commercial use, no credit needed (CC0, MIT, OFL, SIL or similar) |
| 🟡 | Free for commercial use, **credit required** (CC BY or the site's own attribution licence) |
| 🔵 | Free tool or free plan (you make things with it; what you make is yours) |
| 🟣 | Free, but **check each item**. Mixed licences on one site |

> No paid-only sites, no "free trial" traps. Some sites also sell premium items; this list only points at their free stuff. Licences can change, so check the site before shipping a product.
